# Study Companion Game

A small Godot 4.2.7 portrait study companion game prototype inspired by a warm, companion-driven mobile experience.

## Run it

1. Open this folder in Godot 4.2.7.
2. Import the project.
3. Press F5 to run.

## Included features

- Main home screen with a male lead studying at a desk
- Simple character interaction
- Study session flow with subject, time, and companion selection
- Pomodoro-style countdown timer
- Study history recording
- Study coin rewards
- Daily and weekly task tracking
- 2D character and UI art without external assets

## Notes

This is a working prototype focused on the requested systems and gameplay loop, not a full production art pipeline.
